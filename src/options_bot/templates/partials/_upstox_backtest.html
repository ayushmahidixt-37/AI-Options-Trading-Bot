Historical backtest (Upstox)

Read-only historical data from Upstox, used only for offline backtesting. Upstox can never place an order and is not a second trading broker. Disabled unless UPSTOX_BACKTEST_ENABLED=true and UPSTOX_ACCESS_TOKEN is configured.

7 · Strategy validation (Upstox)

The stricter check: compares the documented variants (including any "Custom" idea you've promoted into the code) across non-overlapping development/validation/untouched-test ranges, so a promising idea has to survive on data it never influenced. Uses Upstox data only — never touches Angel or live/forward-paper trading.
